# HOME AI Bridge — Proxmox VE LXC Installer

Публичный **только установщик** для приватного проекта [HOME AI Bridge](https://github.com/DeadSoulf/home-ai-bridge). Этот репозиторий **не содержит** исходников сервера, ключей, токенов или конфигурации устройств.

## Установка одной командой

Выполните **в Shell хоста Proxmox VE от root**:

```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/DeadSoulf/home-ai-bridge-installer/main/install.sh)"
```

Скрипт предложит выбрать свободный **CTID**, хранилище диска, хранилище шаблонов, сетевой мост и режим IPv4 (DHCP по умолчанию или статический). Для фактического создания контейнера нужно ввести `yes`.

Поскольку серверные исходники находятся в **приватном** GitHub-репозитории, скрипт запросит **fine-grained Personal Access Token** GitHub, настроенный только на репозиторий `DeadSoulf/home-ai-bridge` и разрешение **Contents: Read-only**. Токен вводится скрыто через терминал и используется только для временного скачивания архива. Он не передаётся внутрь LXC и не сохраняется на диск как отдельный файл.

После скачивания создаётся **новый unprivileged Debian 13 LXC** (1 vCPU, 512 МБ ОЗУ, 4 ГБ диск), устанавливается Node.js и HOME AI Bridge как служба systemd. По умолчанию сервер слушает **только 127.0.0.1:8787**, без внешнего доступа. Существующие LXC и Windows-версия HOME AI Bridge не изменяются.

### Проверка

Замените `220` на созданный CTID:

```bash
pct exec 220 -- systemctl status home-ai-bridge --no-pager
pct exec 220 -- curl -fsS http://127.0.0.1:8787/health
```

Связь с агентами Asus/server через WireGuard, разрешённые адреса источников, реестр устройств и MCP-туннель настраиваются **отдельно** после проверки LXC.

### Перед запуском

[Просмотрите install.sh](https://github.com/DeadSoulf/home-ai-bridge-installer/blob/main/install.sh): удалённый shell-скрипт выполняется с правами root на гипервизоре. Этот репозиторий не аффилирован с Proxmox Community Scripts; используется только похожий способ запуска.
